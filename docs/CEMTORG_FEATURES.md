# Tender Auto: аукционы, PDF, предварительная логистика

Патчер рассчитан на свежий архив `tender_auto_1792594798879.zip`.
Он не устанавливает сервер, не трогает ключи, лицензию, базу решений и старые
отчёты. Постоянные резервные копии не создаются. Программа должна быть закрыта.

## Установка из Windows CMD

Положите `patch_cemtorg_features.py` в корень Tender Auto рядом с `gui.py`.
Откройте CMD в этой папке:

    python -m pip install "reportlab>=4.2,<6"
    python -X utf8 patch_cemtorg_features.py --check
    python -X utf8 patch_cemtorg_features.py --apply
    python gui.py

`--check` не меняет исходники. `--apply` также сначала проверяет совместимость
и запускает офлайн-тесты без обращения к ЕИС, LLM, ключам и лицензии.
Если версия не совпала — ничего не записывается; принудительного режима нет.
При обычной ошибке записи восстанавливаются исходные байты из оперативной памяти.
От отключения питания посередине многофайловой записи полной гарантии нет.

Эта версия подходит и для исходного ZIP, и для уже установленного предыдущего
патчера трёх доработок. Замените сам файл патчера и повторите `--check`/`--apply`.
Неизвестные ручные изменения по-прежнему не перезаписываются.

## 1. Выборка Цемторга

- По умолчанию проходят только подтверждённые электронные аукционы 44-ФЗ.
  Ценовые предложения видны анонимно, снижение цены возможно на ЭТП по ст. 49.
- Используются коды маршрутов карточек ЕИС `ea20`, `ea15`, `ea44`.
  Незнакомый/закрытый способ и 223-ФЗ автоматически не включаются.
- Запросы ограничиваются 44-ФЗ; способ закупки проверяется по каждой полученной
  карточке, а не по догадке о значении параметров ЕИС. Пять страниц не являются
  гарантией полного охвата всех аукционов на ЕИС.
- Открытый конкурс и запрос котировок не приравниваются к аукциону.
- Последние 7 календарных дней, включая сегодня, и все 5 страниц по каждому
  слову сохраняются. Пустая страница не прерывает проход Цемторга.
- Журнал показывает число отсеянных по способу закупки; другие профили не меняются.
- Отключить фильтр вручную: `cemtorg_auction_only: нет` в `sampler_config.txt`.
  Профильный шаблон также обновлён.

## 2. PDF и DOCX

Для новых квалифицированных отчётов создаются оба файла. PDF имеет краткую
первую страницу и полную аналитику далее, без принудительного ограничения страниц.
Все строки ответа, повторные разделы, строки/ячейки таблиц и текст вокруг таблиц
сохраняются. PDF не сокращает и не пересказывает аналитику моделью.
Кириллица встроена шрифтом DejaVu Sans; Word для PDF не требуется.

Только в отчётах Цемторга на первом листе размещён оригинальный логотип
«Каменный цветок» с официального сайта Цемторга, без перерисовки и изменения
пропорций, с подписью «Подготовлено для Цемторга». Автор аналитики — Тендер Авто.
Логотип встроен в установку, поэтому при создании PDF интернет не нужен.
Источник: https://cemtorg.ooo/wp-content/uploads/2021/01/logo.png
В существующие PDF логотип задним числом не добавляется.

DOCX оставлен для сравнения и старой RFQ-цепочки. Старые отчёты не удаляются и
массово не конвертируются. Остаточные DOCX текущего незавершённого запуска при
подхвате получают PDF из уже существующего содержимого DOCX.

Сводка содержит относительные ссылки на PDF. Итоговый ZIP включает PDF,
DOCX и сводку. Для Цемторга не добавляются блоки поиска поставщиков/их email,
RFQ и Китай; договорные обязанности поставщика из ТЗ сохраняются.

## 3. Логистика

В каждом PDF Цемторга есть отдельная предварительная оценка:
производство «Каменный цветок», д. Непецино, г.о. Коломна → адрес из аналитики.
Транспорт: MAN с бортовым полуприцепом. Открытый или крытый — уточняется.
Совместимость с навалочным грузом автоматически не предполагается.

В `config/cemtorg_logistics.json` лежат редактируемые СИНТЕТИЧЕСКИЕ значения:

- расход 32 л/100 км;
- топливо 75 руб./л;
- прочие расходы 35 руб./км (водитель, обслуживание, износ; без топлива);
- фиксированная часть 3 000 руб. на рейс;
- резерв 10%;
- демонстрационные, НЕ ПРОВЕРЕННЫЕ расстояния: Москва 120 км,
  Санкт-Петербург 850 км, Курск 650 км от Непецино в одну сторону.

Эти расстояния — примеры для демонстрации работы формулы, НЕ результат
построения маршрута. Перед рабочим использованием замените километраж
проверенными значениями, укажите источник в `source`, поставьте `synthetic: false`.
Тарифы всё равно остаются сценарными, пока не сверены с Цемторгом.
Для нового направления добавьте строку в `routes`; `match_all` — точные слова,
которые должны одновременно встречаться в адресе (можно добавить регион/улицу).

Пробег = 2 × расстояние в одну сторону (обратный рейс порожний).
Топливо = пробег × расход / 100 × цена литра.
Прочие расходы = пробег × ставка на км.
Итог = (топливо + прочие расходы + фиксированная часть) × (1 + резерв / 100).

Это стоимость ОДНОГО рейса, не всей поставки. Вместимость, число рейсов,
упаковка и график партий не выдумываются. Сумма не меняет решение аналитики.
Платные дороги, ожидание и особые требования нужно проверить отдельно;
фиксированная часть — не доказательство, что эти расходы покрыты.

Если адрес/маршрут неизвестен, есть несколько адресов или ошибка конфигурации —
PDF явно пишет «Не рассчитано» и причину. Ноль вместо неизвестной цены не ставится.
Новые внешние API и платные сервисы не подключены.

## Повторный анализ

Патчер не сбрасывает историю решений. При необходимости повторной аналитики
используйте существующий `--force` для выбранной выгрузки/номеров; не удаляйте
всю базу решений ради проверки PDF. Для новой выборки нажмите «Собрать выборку».
