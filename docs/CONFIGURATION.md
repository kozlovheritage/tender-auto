# Настройка своей копии

## 1. Примеры вместо клиентских настроек

Из корня проекта:

```bat
python scripts/setup_example.py
```

Команда копирует только отсутствующие файлы, ничего не перезаписывает:

- `examples/sampler_config.txt` → настройки сборщика и профиль Цемторга;
- профиль и условный каталог из `profiles/cemtorg/*.example.json`;
- пример стоп-факторов → `config/stop_factors.txt` и профиль;
- пустые настройки отправителей и дополнительные бренды.

Создаётся `config/active_profile.txt` со значением `cemtorg`.
Именно имя профиля включает специальные ветки сценария производителя.
Это демонстрационная конфигурация, а не полный каталог реального клиента.
Пример каталога содержит вымышленные позиции и URL `example.com`.

`publish_days_back: 6` означает сегодня плюс шесть предыдущих дней —
семь календарных дней включительно. `cemtorg_pages_per_term: 5` задаёт
обход пяти страниц. После нулевой страницы обход не заканчивается сам.

Сборщик также использует встроенные поисковые слова своего сценария;
перед новым клиентом проверьте `sampler.py`, а не только текстовый конфиг.
`base_url` позволяет задать собственный поисковый URL; не помещайте
в отслеживаемые файлы ссылки с паролями или токенами.

## 2. AI, поиск и отправка писем

В `examples/secrets.txt.example` перечислены поля без значений.
Создайте собственный локальный `secrets.txt` либо используйте переменные
окружения, поддержанные загрузчиком:

- `OPENROUTER_API_KEY`, `DEEPSEEK_API_KEY` — провайдеры AI;
- `LANGSEARCH_API_KEY` — поиск;
- `GMAIL_ADDRESS`, `GMAIL_APP_PASSWORD` — опциональная отправка;
- остальные legacy-поля поддержаны кодом, но реальные аккаунты не включены.

Наличие модуля не означает, что он включён для каждого профиля.
Цемторгу не нужны поиск поставщиков и RFQ. Для другого профиля отдельно
настройте локальный `sender_config.json` и шаблоны.
Не храните рабочие значения в `*.example`.

## 3. Собственная офлайн-лицензия

Публичная копия не включает рабочие лицензии и секрет автора.
Для разработки своей сборки в CMD сгенерируйте собственный секрет
в окружении текущего терминала, не выводя его:

```bat
for /f %S in ('python -c "import secrets; print(secrets.token_hex(32))"') do @set "TENDER_AUTO_LICENSE_SECRET=%S"
python keygen.py
```

В `.bat` вместо `%S` используйте `%%S`.
Генератор попросит параметры и выдаст ключ вашей сборки. Введите его
в интерфейсе активации или сохраните локально в `license/key.txt`.
Запускайте `python gui.py` из того же настроенного терминала.

Для последующих запусков потребуется тот же секрет. Храните его вне Git
в защищённом месте; не генерируйте новый при каждом запуске.
Это локальная настройка разработки, не инструкция по распространению
единого секрета между клиентами и не серверная защита.

## 4. Логистика

`config/cemtorg_logistics.json` содержит только открытые демонстрационные
значения. Все расстояния и ставки нужно подтвердить перед использованием.
Расчёт — один рейс туда-обратно, не стоимость всей поставки и не число машин.
Полная формула и ограничения: [CEMTORG_FEATURES.md](CEMTORG_FEATURES.md).

## 5. Сборка и проверка поставки

Сборка Windows описана в README. Перед ней создайте собственные настройки.
Не публикуйте полученную папку автоматически: `build_all.spec` и
`assemble_product.py` способны включать локальные рабочие файлы.
Публичная копия намеренно не содержит готового активированного EXE.
