# Тендер Авто · Tender Auto

Десктопная система для первичного отбора и анализа закупок из ЕИС:
**выборка → документы → извлечение текста → AI-анализ → проверка условий → отчёт**.

Публичный технический кейс и исходники проекта. Целевая среда — Windows,
интерфейс — Python / PySide6. Это не облачный сервис и не робот подачи ставок.

## Что реализовано

| Направление | Возможности |
|---|---|
| Выборка ЕИС | Поисковые запросы, Excel-выгрузка, даты и страницы из настроек |
| Документы | Скачивание, проверка содержимого, обработка архивов и ссылок; HTML-ответ не принимается за успешную загрузку документа |
| Устойчивость | Общая координация запросов ЕИС, интервалы, ограниченные повторы, обработка 403/503 и отложенный повтор вместо ложного бизнес-отказа |
| Извлечение | PDF, DOCX, XLS/XLSX и другие поддерживаемые форматы; OCR при наличии Tesseract; старый DOC — через Word COM в Windows |
| Аналитика | AI-разбор условий закупки, стоп-факторы, Python-проверки и история решений |
| Профили | Разные правила и наборы функций для разных сценариев использования |
| Интерфейс | Выборка, запуск/остановка анализа, история, отчёты, понятные сообщения о ходе обработки и проблемах ЕИС |
| Отчёты | PDF и DOCX, Excel-сводка со ссылками, комплект результатов в ZIP |
| Дополнительные модули | Поиск поставщиков и контактов, RFQ-очередь и отправка — только для профилей, где эти функции включены |

### Последние доработки: сценарий Цемторга

- Только подтверждённые электронные аукционы **44-ФЗ**; открытый конкурс
  и запрос котировок не считаются аукционом. Процедуры 223-ФЗ автоматически
  не включаются. Цены предложений анонимны; торги проходят на ЭТП, не в программе.
- Последние **7 календарных дней, включая сегодня**, и все **5 страниц**
  по ключевому слову, даже если отдельная страница не дала новых строк.
  Это ограниченный обход, а не гарантия полноты всей ЕИС.
- Читаемый многостраничный PDF с первой страницей-резюме и полной аналитикой
  далее. Текст и таблицы не сокращаются ради одной страницы. DOCX сохранён.
- Логотип клиента с официального сайта; автор отчёта — Тендер Авто.
- Предварительная логистика от Непецино: явно синтетические ставки
  и демонстрационные расстояния, расчёт одного рейса туда-обратно.
  Неизвестный маршрут не превращается в нулевую стоимость.
- Без поиска поставщиков, их email, RFQ и папки «Китай» в этом профиле.

Подробности и ограничения: [доработки Цемторга](docs/CEMTORG_FEATURES.md),
[архитектура](docs/ARCHITECTURE.md), [история изменений](CHANGELOG.md).

## Быстрый старт из исходников

Рекомендуемая исходная среда: **Windows 10/11, Python 3.11, CMD**.
Для работы нужны свои настройки, доступ к ЕИС и ключ подходящего AI-провайдера.
Запуск Windows GUI и сборка EXE не проверяются Linux-тестами.

```bat
git clone https://github.com/kozlovheritage/tender-auto.git
cd tender-auto
python -m pip install -r requirements.txt
python scripts/setup_example.py
```

Последняя команда создаёт только отсутствующие настройки из публичных примеров.
Это **учебные значения, не рабочая конфигурация клиента**. Замените каталог,
стоп-факторы, поисковые слова и параметры расчёта своими.

1. Настройте AI через переменные окружения либо локальный `secrets.txt`.
   Список полей есть в `examples/secrets.txt.example`; настоящие значения
   никогда не коммитятся.
2. Настройте собственную локальную лицензию для своей сборки:
   [конфигурация и лицензирование](docs/CONFIGURATION.md).
   Секрет и лицензии автора в репозитории отсутствуют.
3. При необходимости установите Tesseract OCR и Microsoft Word для старых DOC.
4. Откройте интерфейс:

```bat
python gui.py
```

Запуск без GUI:

```bat
python -X utf8 -u sampler.py
python -X utf8 -u tender_auto.py
```

Не запускайте одновременно несколько процессов, обращающихся к ЕИС.
Проверяйте параметры перед живым сбором: запросы идут с устройства оператора.

## Проверки

```bat
python scripts/check_public_source.py
python -m unittest discover -s tests -p test_cemtorg_features.py
python -m unittest discover -s tests -p test_eis_documents.py
python -m unittest discover -s tests -p test_eis_reliability.py
python -m unittest discover -s tests -p test_public_license.py
```

Для этих офлайн-проверок используются фиктивные документы, временные папки
и подменённые сетевые ответы, а не реальные данные ЕИС или клиента.
Остальные исторические тесты сохранены в `tests/`, но не объявлены
полностью проверенной матрицей совместимости.

## Сборка для Windows

После настройки исходников и установки PyInstaller на Windows:

```bat
python -m pip install pyinstaller
python -m PyInstaller --noconfirm build_all.spec
python assemble_product.py
```

Сборка формирует `dist/TenderAuto`; `installer.iss` предназначен для Inno Setup.
Проверяйте состав поставки: текущая локальная упаковка может включать
рабочие настройки и ключи из вашей папки. Это **не способ распространения
авторских секретов** и не автоматически безопасный многоклиентский релиз.

## Что намеренно отсутствует

- API-ключи, пароли, прокси с авторизацией, секрет подписи и лицензии;
- реальные клиентские каталоги, стоп-факторы и настройки отправителей;
- документы закупок, результаты анализа, базы, журналы и история;
- установочные архивы, EXE, старые резервные копии и внутренние материалы.

Вместо закрытых настроек — примеры в `examples/` и `profiles/cemtorg/*.example.json`.
Подробности: [безопасность публичной копии](SECURITY.md).

## Статус и границы

Публикация объединяет последний переданный снимок исходников и последний
применённый патч аукционов/PDF/логистики. Дополнительные изменения на сторонних
компьютерах, не переданные в проект, сюда автоматически не попадают.

«Профилированное серверное ядро», управление подписками и автообновления —
**план, не реализованный серверный продукт**. Сейчас серверный трек отложен.
Программа не гарантирует отсутствие блокировок ЕИС, верность AI-выводов,
точность демонстрационной логистики или победу в закупке.
Условия и исходные документы требуют проверки человеком.

Публичная доступность исходников сама по себе не означает предоставления
отдельной open-source лицензии. Лицензии сторонних шрифтов сохранены рядом
с ресурсами. Логотип клиента используется как иллюстрация оформления отчёта,
не как логотип Тендер Авто.
