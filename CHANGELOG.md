# Изменения

## Актуализация публичного исходника — октябрь 2026

Источник: последний переданный снимок десктопной программы и применённый
патч трёх доработок Цемторга. Это не новая придуманная версия установщика.

### Добавлено

- Фильтр подтверждённых электронных аукционов 44-ФЗ для сценария Цемторга.
- PDF-отчёты с полной аналитикой, встроенной кириллицей и логотипом клиента.
- Сценарный расчёт одного логистического рейса; неизвестные маршруты
  явно помечаются как нерассчитанные.
- Сохранение пары PDF/DOCX, ссылки на PDF в сводке и комплект результатов.
- Офлайн-регрессии новых функций, безопасные примеры настройки,
  документация запуска, архитектуры и ограничений.

### Перенесено из актуального локального исходника

- Обход пяти страниц по слову и семидневное окно выборки Цемторга.
- Интерфейсный журнал этапов, компактные счётчики и сообщения о сбоях ЕИС.
- Исключение временных Excel-файлов из выбора входной выгрузки.
- Проверка ответов при скачивании документов, обработка HTML вместо файла,
  сетевые интервалы и ограниченные повторы.
- Разделение сетевой неполноты и бизнес-отказа.
- Отключение нерелевантных поставщиков, RFQ и китайских папок для Цемторга.

### Только для публичной копии

- Закрытые файлы заменены примерами; секрет подписи лицензий не публикуется.
  Для своей сборки используется `TENDER_AUTO_LICENSE_SECRET`.
- Устаревшие `files.txt`, `tree.txt` и генератор старых клиентских профилей
  не входят в актуальное дерево. История Git не переписывается.
- Серверное ядро не выдаётся за уже реализованную возможность.

Предыдущий публичный снимок был опубликован в сентябре 2026 года.
